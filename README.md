
# Kewyword game

Keyword game - игра в которой нужно быстро вводить слова появляющиесе на экране чтобы хп врага уменьшалось. Сколько хп отнимается зависит от количества ошибок и затраченного времени(это можно исправить в коде). Пока что доступны только массивы с английскими словами такими, как Countries(Страны), Hard(Сложные), All(все).
