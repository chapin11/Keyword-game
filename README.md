
# Keyword Game

A fast-paced typing game where players must quickly enter words appearing on the screen to defeat enemies. Each correct word reduces the enemy's HP, with damage calculated based on accuracy and completion time.

![Game Preview](/preview.PNG)
![Gameplay](/preview2.PNG)

## 🎮 Features

- **Multiple Word Categories**: Choose from different word sets including:
  - 🌍 Countries
  - 🔥 Hard (challenging words)
  - 📚 All (complete word collection)
- **Dynamic Damage System**: Damage dealt depends on typing accuracy and speed
- **Customizable Settings**: Adjust damage calculation parameters in the code
- **Responsive Design**: Built with Bootstrap for seamless gameplay across devices

## 🛠️ Technologies Used

- **JavaScript** - Core game logic and interactivity
- **Bootstrap** - Responsive UI framework
- **HTML5/CSS3** - Structure and styling

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Select a word category and start playing!

## ⚙️ Configuration

You can customize the damage calculation formula by modifying the relevant parameters in the source code to adjust:
- Error penalty
- Time-based bonuses
- Base damage values

### 🎮 Описание игры

Быстрая игра на набор текста, где игроки должны оперативно вводить слова, появляющиеся на экране, чтобы побеждать врагов. Каждое правильно введенное слово уменьшает здоровье врага (HP), при этом урон рассчитывается на основе точности и времени завершения.

![Геймплей](/preview2.PNG)

### ✨ Возможности

- **Несколько категорий слов**: Выбирайте из различных наборов слов:
  - 🌍 Страны
  - 🔥 Сложные (сложные слова)
  - 📚 Все (полная коллекция слов)
- **Динамическая система урона**: Наносимый урон зависит от точности и скорости набора текста
- **Настраиваемые параметры**: Изменяйте параметры расчета урона в коде
- **Адаптивный дизайн**: Создан с использованием Bootstrap для бесшовного геймплея на любых устройствах

### 🛠️ Используемые технологии

- **JavaScript** - Основная логика игры и интерактивность
- **Bootstrap** - Фреймворк для адаптивного интерфейса
- **HTML5/CSS3** - Структура и стилизация

### 🚀 Начало работы

- Базовые значения урона
